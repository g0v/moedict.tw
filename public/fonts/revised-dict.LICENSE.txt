Purpose
  Render MOE's own plane-15 Supplementary Private Use Area (U+F0000–FFFFF)
  variant headwords — 110 single-char PUA titles in the dictionary
  (e.g. U+F0009 = 「丑」的異體字). No shipped EduKai / 全字庫 web face
  covers these codepoints. The @font-face is scoped with
  `unicode-range: U+F0000-FFFFF` so the browser only fetches this 9.17 MiB
  file when a PUA codepoint is actually on the page.
