Methodology and rationale

The consolidation rules were intentionally conservative: fix only what the active surface owns; verify instead of reimplementing when the report is already satisfied.

Active vs frozen surfaces

www.moedict.tw is the active React/Vite + Cloudflare Workers site. moedict-webkit is frozen historical UI; its issues can still describe real symptoms, but implementation belongs in moedict.tw when current code owns the behavior.

Local-code boundary

Branch work was appropriate when source, R2 lookup behavior, generated indices, CSS, or frontend interaction could be changed and tested locally. Upstream data/license gaps were documented rather than guessed.

Semantic supersets

The unified branch did not blindly cherry-pick every isolated commit. Duplicate TWBLG badge work, stroke UX overlap, and CNS generated output were reconciled into current commits that preserve observable contracts.

Data integrity

No dictionary definitions were edited: CC BY-ND dictionary content remains data-of-record. Generated or source-owned artifacts were changed only where pipeline contracts justified them.

No staging rationale: consolidation did not push, deploy, create staging, or touch GitHub. All Batch 1 contracts were locally verifiable through build, API, unit/integration/e2e, generated data checks, browser rendering, and dry-run corpus generation. Deploy and staging are operational rollout steps, not prerequisites for this local integration report.

#260 — 許願：讓「全字庫」加入萌典的搜尋資料

Why it matters: #260 began as a product reroute/spec item, but the unified branch implements the first complete model: a CNS attribute fallback that never pretends CNS is a fifth dictionary, never shadows real dictionary entries, and keeps attribution/license boundaries visible.

CNS no-shadow behavior and dispatch

Two distinct precedence rules govern CNS integration. In the UI, the existing a/t/h/c dictionary lookup completes first; the CNS fetch and fallback card render only after the lookup returns no hit and the query is exactly one Unicode scalar covered by CNS data. In the Worker, the explicit /api/cns/{char}.json route matcher is placed intentionally before the generic .json dictionary catch-all so it remains reachable as its own named path. CNS does not extend DictionaryLang — it is a separate attribute source, not a fifth dictionary.

  • Dedicated cache tags for CNS data rather than reusing dictionary tags.
  • Offline /cns/ mirror so the fallback card can work with deterministic local fixtures.
  • PUA exclusion in the generated first-pass corpus.
